# 实验结果总览（全部实验完成）

数据：BEIR NFCorpus。检索器冻结：BM25 和 E5-small-v2。主指标为 NDCG@10。配置在读取测试集之前已锁定（`lock.json`，2026-11-19）。
本文所有数字均来自 `results/` 下的文件，括号内注明出处。

## 一句话结论
- **自适应融合本身没有收益**：只加 L2 的自适应融合 R1 在 dev 和 test 上都不如最优固定融合。
- **锚定把它拉回到略优于固定融合的水平**：R2/R3 在 test 上提升 +0.003 NDCG@10，95% CI 的下界恰好在 0 以上。在 dev 上同样的比较是 −0.002，所以这个提升很小，也很脆弱。
- **锚定最明显的作用在优化层面**：它显著改善了目标函数的曲率，使 GD 从不收敛变为收敛，并把严重退化查询的比例降到原来的约 1/3。
- **按分歧加权（R3）相比统一锚定（R2）没有额外收益**：两者的差值为 +0.0001，95% CI [−0.0006, +0.0008]。

## RQ1：自适应权重是否有收益（E0、E1、E3、test）
| 系统 | dev NDCG@10 | test NDCG@10 | test 严重退化比例 |
|---|---|---|---|
| BM25 | 0.2662 | 0.3075 | 29.4% |
| Dense | 0.3221 | 0.3256 | 21.4% |
| RRF k=20（dev 选出） | 0.3152 | 0.3420 | 15.5% |
| **固定融合 α=0.10（dev 最优）** | **0.3377** | 0.3476 | — |
| R1（仅 L2） | 0.3349 | 0.3441 | 10.8% |
| R2（统一锚定） | 0.3359 | 0.3508 | 2.8% |
| R3（高分歧锚定） | 0.3357 | **0.3509** | 3.1% |
| R4（低分歧锚定） | 0.3361 | 0.3465 | 8.7% |

（出处：`e1_baselines.md`、`e3_models.md`、`test_report.md`）

- **E0**：逐查询最优权重相对固定融合的空间为 Gap = 0.0365，属于“high”区间。但各特征与逐查询最优 α 的 Spearman 相关系数绝对值都不超过 0.19，即潜在空间存在，但特征很难预测它。
- **主要比较（预先登记）**：R3 − 固定融合，test 均值差 +0.0032，95% CI [+0.00002, +0.0065]，10,000 次 Bootstrap 中有 97.6% 大于 0。
- **R3 相对 R1** 提升 +0.0068，95% CI [+0.0011, +0.0128]，说明锚定项本身是有效的。
- **改进集中在少数查询上**：R3 只在约 15% 的测试查询上优于固定融合，其余查询基本持平。

## RQ2：分歧锚定何时有效（E3、E5、E6）
- **R2 与 R3 几乎相同**：两者学到的 α 几乎没有差异（test 上的 α 均值分别为 0.184 和 0.182，标准差为 0.075 和 0.068；见 `test_results.json`）。按 Jaccard 分歧给锚定加权没有带来额外作用。
- **R4（低分歧加权锚定）明显较弱**：test 0.3465，严重退化比例 8.7%，介于 R1 和 R2 之间。
- **E5 消融**（test NDCG@10；`e5.json`、`test_report.md`）：
  - 去掉 g 特征、保留锚定：0.3509，与 R3 相同。g 作为输入特征没有贡献。
  - 去掉锚定、保留 g：0.3441，等同于 R1。所有收益都来自锚定项。
  - 均匀负例：在 dev 上三个模型都变差，在 test 上 R2/R3 却变好（0.3536 和 0.3531）。dev 与 test 的结论方向相反，幅度约 ±0.003，与 R3 相对固定融合的提升同一量级。所以这一量级的差异应视为噪声范围。
  - 不跳过前 20 名：dev 0.3363（略好），test 0.3487（较差）。训练损失与 NDCG@10 不一致的问题（见第二阶段的分析）确实存在，但这个变体并没有在两个集合上同时胜出。
- **E6 多种子**：重新抽取弱负例，5 个种子下 test NDCG@10 的标准差都不超过 0.0003，远小于模型之间的差异。结论不受采样随机性影响。

## RQ3：优化算法与曲率（E4，`e4_report.md`）
| 目标 | 方法（锚点起点） | 是否收敛 | 迭代次数 | f / g / H 调用次数 | 时间（中位数） |
|---|---|---|---|---|---|
| R1 | GD（Armijo） | **否**（2,000 次，‖∇J‖∞=6.7e-5） | 2000 | 2001/2001/0 | 80.0 s |
| R1 | BFGS | 是 | 50 | 55/55/0 | 2.05 s |
| R1 | L-BFGS-B | 是 | 11 | 13/13/0 | 0.49 s |
| R1 | Newton-CG | 是 | 8 | 9/9/8 | 0.91 s |
| R1 | trust-exact | 是 | 6 | 7/7/7 | 0.76 s |
| R3 | GD（Armijo） | 是 | 334 | 335/335/0 | 44.6 s |
| R3 | BFGS | 是 | 29 | 32/32/0 | 3.94 s |
| R3 | L-BFGS-B | 是 | 9 | 11/11/0 | 1.38 s |
| R3 | Newton-CG | 是 | 6 | 7/7/6 | 2.35 s |
| R3 | trust-exact | 是 | 5 | 6/6/6 | 2.41 s |

- **曲率与 GD 收敛**：在 R1 的解处 λ_min = 1.2e-3、κ = 21.9；在 R3 的解处 λ_min = 1.7e-2、κ = 9.8。Armijo 每次都接受步长 1（f 调用次数 = 1 + 迭代次数），所以 GD 等价于步长为 1 的固定步长梯度下降，局部收敛率约为 1 − λ_min。
  - R1：预计需要约 6,300 次迭代，实际 2,000 次未收敛。
  - R3：预计约 440 次，实际 251–336 次。
  - **锚定项增加的曲率 2γh_q·a_q² 是 GD 能够收敛的直接原因。**
- **κ 随 γ 的变化不是单调的**（`figures/e4_kappa_vs_gamma.png`）：γ=0.1 时 κ 反而上升，因为 λ_max 增长得比 λ_min 快；到 γ=1 时 κ 才明显下降（λ=1e-3 时从 21.9 降到 9.8）。
- **非凸性**：R1 在锚点起点处的 Hessian 不定，R3 在同一点处的 Hessian 正定。在锚点附近随机取点（N(0,0.5²) 扰动），出现负曲率的比例在 R1 是 95%，在 R3 是 74%。也就是说，锚定把起点附近的区域变得更接近凸的。
- **多起点**：每个目标各有 3 个起点 × 5 种算法。所有收敛的解中，J 的差异小于 1e-8，参数之间的距离小于 3e-3，解处的 Hessian 全部正定。这说明各算法收敛到同一个严格局部极小，但不能据此断定是全局最优。
- **按调用次数**：二阶方法最少（6–8 次迭代），L-BFGS-B 次之（约 10 次），BFGS 约 30–50 次。**按墙钟时间**：L-BFGS-B 最快，因为 d=6 时 Hessian 很便宜，但每次调用仍要遍历 259k 个样本对。
- **计时误差**：非锚点起点的计时只跑了一次，个别运行比中位数慢了约 3 倍（如 R1 perturbed_s29 的 BFGS 用了 6.9 s）。比较时间时应以锚点起点的中位数为准。

## 讨论要点（建议写入报告）
1. **训练目标与评价指标不一致**：R1 学到的 α 平均约 0.32，而 NDCG 最优的固定 α 是 0.10。负例的来源决定了成对损失偏好的 α：均匀负例对应 0.30，跳过前 20 名的困难负例对应 0.20，不跳过时对应 0.10。在没有锚定的情况下，自适应模型会被训练损失拉离 NDCG 的最优点。锚定把 α 拉回 α0 = 0.15 附近，因此起到了作用。
2. **R2/R3 的最优 γ 落在网格上界 γ=1**，说明更强的锚定可能还会更好，即进一步收缩到固定融合。这本身也说明，现有特征能够提供的自适应信息很有限。
3. **dev 与 test 的结论方向不一致**：R3 在 dev 上略低于固定融合，在 test 上略高；均匀负例在 dev 上更差，在 test 上更好。约 0.003 的差异在 300 多个查询的规模下接近噪声水平，报告中应避免过度解读。
4. **案例**：R3 改进最大的查询，是 BM25 明显优于 Dense 而模型把 α 调高的情形（如 “Is Coconut Milk Good For You?”，+0.18）。退化最大的查询，是 BM25 得 0 分时模型仍把 α 调高到 0.24 的情形（“Apthous Ulcer Mystery Solved”，−0.16）。
